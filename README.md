O tema que eu escolhi foi esteganografia ou a encriptação de dados, ela basicamente mostra como dados podem ser ocultados na internet, escolhi especificamente para falar de LSB e text append, o primeiro utiliza os LSB, least significant bits, eles são os bits ou partes do código que tem menos significado, em uma imagem por exemplo existem diversos pixels que são os quadradinhos que compõem essa imagem, cada pixel tem uma cor que pode ser escrita com 0 e 1, o binário, e nesse número gigante o seu número final é o bit (0 ou 1) menos significativo. 
Para exemplificar o LSB a cor vermelha pode ser escrita como 11111111 00000000 00000000, que quando juntas falam para o pixel mostrar vermelho, o bit menos significativo do vermelho seria o último 0 (11111111 00000000 00000000 <- esse), a esteganografia utilizando o LSB muda vários pixels de uma imagem no último bit para escrever uma mensagem em binário (escrita com 0 e 1), cor seria (01100011 01101111 01110010). Assim a imagem aparenta não mudar para os olhos humanos mas o computador sabe o que está escrito nessas pequenas mudanças.
O text append é mais simples, ele também esconde mensagems mas depois da imagem, uma imagem no computador é uma grande cadeia de 0 e 1, o binário ou os metadados da imagem, o text append coloca uma mensagem depois dos metadados, então o computador lê o código da imagem e mostra ela mas o texto escondido depois da leitura da imagem não aparece.
